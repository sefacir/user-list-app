# BIM308 Angular User List App

Bu proje, Eskişehir Teknik Üniversitesi Bilgisayar Mühendisliği "BIM308 Web Tabanlı Programlama" dersi 3. ödevidir.

## 🧾 Proje Açıklaması

Bu uygulama Angular kullanılarak geliştirilmiş basit bir kullanıcı listeleme sistemidir. JSONPlaceholder API üzerinden kullanıcı bilgileri çekilerek ekranda listelenir.

## 🛠 Kullanılan Teknolojiler

- Angular 17+
- TypeScript
- HTML & CSS
- RxJS
- HTTPClientModule (veri çekme işlemleri için)

## 🌐 API

Veriler şu adresten alınır:  
[https://jsonplaceholder.typicode.com/users](https://jsonplaceholder.typicode.com/users)
